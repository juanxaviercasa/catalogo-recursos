# Validación de exploración visual

| Elemento | Verificación |
|---|---|
| Mapa de decisión | Se abrió desde el catálogo y mostró tres rutas: objetivo, entorno y formato. |
| Resultados guiados | La ruta inicial presentó seis coincidencias y tres fichas sugeridas para abrir. |
| Lenguaje de navegación | El disparador superior ya indica **Descargas** y las tarjetas muestran **Agregar** o **En descargas**. |

| Árbol editorial | Se abrió como vista alternativa y expuso 65 ramas de categoría y familia; una rama desplegada mostró archivos concretos. |
| Mapa contextual | La ficha abierta desde el mapa de decisión contiene el bloque «Mapa contextual», con conexiones derivadas de usos, compatibilidad y etiquetas. |
| Lista de descargas | El resumen inferior se actualizó a «en tu lista», «Ver lista» y «Descargar lista»; las tarjetas muestran «Agregar» o «En descargas». |

| Responsive | Se capturó la página a 375 × 812 px; las rutas visuales usan reglas de una columna y los controles de la lista de descargas permanecen disponibles. |
| Compilación | La compilación de producción finalizó correctamente tras añadir mapas, árbol y la nueva nomenclatura. |
